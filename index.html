あなたのGitHubのVaultに接続します。
スマホだけで動き、PCは不要です。

トークンの作り方
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. 「Generate new token」を押す
  3. Repository access で Only select repositories → Vaultのリポジトリを選ぶ
  4. Permissions → Repository permissions → Contents を Read and write に
  5. 生成された github_pat_... をここに貼る

カード

思考セッションはリアルタイムの往復が命なので、ClaudeアプリのCodeタブに引き継ぎます。ボタンを押すと、あなたのVaultの流儀(3段ラリー・ストレッチ原則)を守らせる指示文がコピーされます。貼り付けて送信してください。

使い方
  1. テーマを書いて上のボタンを押す(指示文がコピーされます)
  2. Claudeアプリ → Codeタブ → リポジトリを選ぶ
  3. 貼り付けて送信 → 対話開始
  4. 終わったら「保存して」と言えばVaultに記録されます
